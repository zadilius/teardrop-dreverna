# Teardrop namelio nuoma · Dreverna

Vienos puslapio svetainė teardrop tipo prikabinamo namelio nuomai šalia Drevernos.

## 🚀 Deploy į Vercel

### Variantas 1: Per GitHub (rekomenduojama)
1. Sukurk naują repository GitHub'e (pvz. `teardrop-dreverna`)
2. Įkelk `index.html` failą į repository (per drag & drop GitHub web sąsajoje arba `git push`)
3. Eik į [vercel.com](https://vercel.com) → **Add New** → **Project**
4. Pasirink savo GitHub repository
5. Spausk **Deploy** (jokių nustatymų keisti nereikia – Vercel automatiškai aptiks static site)
6. Per ~30 sek. gausi gyvą URL (pvz. `teardrop-dreverna.vercel.app`)

### Variantas 2: Tiesiogiai į Vercel (be GitHub)
1. Eik į [vercel.com](https://vercel.com)
2. Spausk **Add New** → **Project**
3. Pasirink **Browse** ir įkelk visą folder'į su `index.html`
4. Deploy

## 🌐 Domenas

Po deploy gausi `.vercel.app` URL nemokamai. Jei nori savo domeno (pvz. `teardrop.lt`):
1. Vercel project → **Settings** → **Domains**
2. Įvesk savo domeną
3. Pakeisk DNS įrašus pas domeno registratorių pagal Vercel instrukcijas

## 📝 Failai

- `index.html` – pilnas vieno failo statinis site (visi paveikslėliai base64, jokių išorinių asset'ų išskyrus Google Fonts)

## ✏️ Kaip pakeisti turinį?

Atidaryk `index.html` su bet kokiu teksto redaktoriumi (VS Code, Notepad++) ir keisk tekstą tiesiogiai HTML. Po pakeitimo:
- Jei naudoji GitHub: tiesiog push'ink pakeitimus – Vercel automatiškai pernaujins site
- Jei įkėlei tiesiogiai: re-upload per Vercel dashboard
